About the Solar Power Prediction Website

This Application is designed for educational, analytical, and research-oriented use.

It provides solar power predictions using machine learning models trained on two datasets. The datasets used in this project are for demonstration and academic purposes only.

The user acknowledges that the predictions depend heavily on the quality, scope, and limitations of the provided datasets.

The Application itself does not collect, store, or sell personal data. While this Application uses machine learning models to estimate future solar performance, the predictions are:

  • approximations,
  • based on historical data,
  • influenced by synthetic or assumed environmental variables,
  • not guaranteed to be correct or reliable.

By using the Application, you acknowledge that all predictions are informational, not factual.

The Application may be updated, modified, suspended, or discontinued at any time without prior notice.
